Tire Suas Dúvidas

Dúvidas Frequentes

Respondemos as perguntas mais comuns de gestores e equipes de TI sobre o e-SUS PEC.

O PEC funciona offline?

Sim! O e-SUS PEC possui um módulo offline que permite o registro de atendimentos e visitas domiciliares mesmo sem conexão com a internet. Quando a conexão for restabelecida, os dados são sincronizados automaticamente com o servidor central, garantindo que nenhuma informação seja perdida.

Como funciona a migração de dados do sistema anterior?

O processo de migração é realizado com suporte técnico especializado. O Ministério da Saúde disponibiliza scripts de importação compatíveis com os principais sistemas legados. Os dados históricos dos pacientes são preservados e organizados no padrão RNDS, garantindo continuidade do cuidado sem interrupção dos serviços.

Quais são os requisitos mínimos de hardware?

Para o servidor: processador 4 núcleos, 8GB RAM e 100GB de armazenamento SSD. Para os terminais de atendimento: qualquer computador ou tablet com navegador moderno (Chrome ou Firefox atualizado) e resolução mínima de 1366x768. Não é necessário instalar software nos computadores dos usuários.

O sistema é seguro? Como são protegidos os dados dos pacientes?

O e-SUS PEC segue todos os protocolos da LGPD e as normas de segurança do Ministério da Saúde. Os dados trafegam criptografados via HTTPS/TLS 1.3, o acesso é controlado por perfis de usuário com autenticação segura, e os backups são realizados automaticamente a cada 24 horas.

O treinamento da equipe está incluído na implantação?

Sim. O pacote de implantação inclui treinamento presencial ou remoto para todos os perfis de usuário (médicos, enfermeiros, ACS, recepcionistas e gestores). Também disponibilizamos videoaulas, manuais em PDF e uma base de conhecimento online acessível 24h para consultas posteriores.
